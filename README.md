# EduHolo Studio • אולפן ההוראה החושית וחיבור NotebookLM

> **פלטפורמת הוראה רב-חושית עתידנית להפיכת תוצרי מחקר ו-NotebookLM לשיעורים חיים ב-3 לחיצות עבור מורים**

---

## 🌟 חזון המערכת
EduHolo Studio מתוכננת לאפשר לכל מורה ואיש חינוך (כולל מורים החוששים מטכנולוגיה) לקחת תוצרי חקר, סיכומים ופודקאסטים מ-**Google NotebookLM**, ולהמיר אותם ב-3 לחיצות למערך שיעור אינטראקטיבי, עשיר ומרהיב בכיתה:
1. **לחיצה 1 — הגדרת השיעור:** בחירת מקצוע (תנ״ך, מדעים, מתמטיקה, חינוך גופני, שפה), שכבת גיל ומבנה הפעילות, בהתאמה אוטומטית לדנ״א והשפה הבית-ספרית.
2. **לחיצה 2 — חיבור תוכן NotebookLM:** הזנת סיכום/טקסט המחברת וקישור תוצרי ה-Studio (פודקאסט Audio Overview, שורטס וידאו, דף מקורות).
3. **לחיצה 3 — יצירה והפעלה:** הפעלת השיעור החי בבמה החושית ושמירתו האוטומטית בספרייה הבית-ספרית המשותפת.

---

## 🚀 רכיבי במת השיעור החושית
* **הולוגרמה 3D אינטראקטיבית:** מודלים תלת-ממדיים חיים מבוססי Three.js עם תאורת אווירה, שליטה בזוויות ואינטראקציה חזותית.
* **מתמטיקה מוחשית וכמויות:** מאזני שוויון והמחשת כמויות ויזואליות לפני פתרון תרגילים מספריים.
* **קרוסלת שלבים חזותית:** המחשת תנועה ושלבים (כגון קפיצה לרוחק מול גובה בחינוך גופני).
* **נגן תוצרי NotebookLM Studio:** הצגת שורטס ופודקאסטים מסוכמים ישירות בבמה.
* **טקסט מנוקד ומילון מונחים חכם:** הדגשת מילים מורכבות, הקראה קולית טבעית ופירוש מיידי להפחתת עומס קריאה.
* **סקר כיתתי מהיר:** בדיקת הבנה מובנית בזמן אמת.
* **מיקוד קשב עדין (Focus Calm):** עמעום הסחות דעת ואפקטים ויזואליים להפחתת עומס תחושתי עבור תלמידים עם קשיי קשב ורגישות חושית.
* **ארכיון וספרייה בית-ספרית:** שמירה ושיתוף מערכי שיעור בין כלל מורי בית הספר.

## 🎨 שפת עיצוב — Luminous Pedagogy
הממשק עוצב על פי עקרונות **Luminous Pedagogy**:
* קנבס כהה עמוק (`#090B12`) המונע עייפות ראייה בהקרנה ממושכת.
* זוהרי אור אטמוספריים וזכוכית מודרנית (Refined Glassmorphism).
* הדגשות סטטוס פדגוגיות: סגול אינדיגו (`#633BF3`), ציאן חי (`#00E5FF`), אזמרגד פדגוגי (`#00E599`).
* טיפוגרפיה מותאמת עברית ואנגלית (`Heebo`, `DM Sans`, `Space Grotesk`).
* תמיכה מלאה במצב כהה / מצב בהיר לבחירת המורה.
