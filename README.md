# EduHolo — מאגר ייעודי פתוח לפדגוגיה חושית, מתמטיקה מוחשית ומחשוב מרחבי

## חזון חינוכי ייעודי
EduHolo היא פלטפורמה פתוחה המוקדשת לפדגוגיה חושית, מתמטיקה מוחשית ומחשוב מרחבי.

### מרכיבי החזון החינוכי:
- **PhET tangible math quantities** — מתמטיקה מוחשית ואינטראקטיבית להמחרשת מושגים כמותיים.
- **3D archaeology** — חקירת מוצגים וארכיאולוגיה בתלת-ממד במרחב הלמידה.
- **Science simulations** — סימולציות מדעיות מתקדמות ללמידה חקרנית.
- **English CLIL** — שילוב הוראת אנגלית בהוראת תכני מדע וטכנולוגיה.
- **ADHD focus mode** — מצב מיקוד והנגשה מותאם לבעלי הפרעות קשב וריכוז.
